# Bybit 暂停 Spread Trading：双腿成交和退出成本要分开看

主类型：量化  
标签：Bybit、价差交易、执行风控  
观察：2026-11-24 约 12:00 UTC

Bybit API 团队公告：12 月 1 日暂停 Spread Trading 产品，并下线相关行情、交易、查询与 WebSocket。受影响包括 REST `/v5/spread/*`、公共行情 `/v5/public/spread`、私有 `spread.order` 和 `spread.execution`。公告未给出准确 UTC 小时，也未说明未成交组合单如何处置或历史记录保留方式；不要把它理解为普通现货/永续 API 同时停用。

关键区别是执行方式，不只是接口改名。现行说明中，专用订单簿同时撮合两腿，已成交的腿则分别落在账户相应的现货、合约市场；常规情况下在各自市场管理。没有公告依据说已经成交的持仓会自动强平或同步结算。改成普通双腿撮合，会新增一条腿先成交、另一腿滑点或部分成交的风险；原价差盘口也不能用简单相减代替，须按两本订单簿和实际成交量重算。

费用情景：按官方基础费率及现行组合费折扣，设每腿名义 1,000 USDT、都吃单，现货 10 bp、USDT 合约 5.5 bp。组合开平名义手续费约 1.55 USDT，分开开平约 3.10 USDT；已有仓位若只比较退出，则 0.775 对 1.55 USDT。费率依地区、交易对和账户而变，例子不含借贷、资金费、滑点，也未取得可执行的同步盘口，不代表存在价差收益。RFQ 是独立功能，公告没有证明可直接替代受影响的组合盘口。
